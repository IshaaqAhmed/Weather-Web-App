Weather Web App.
A simple weather app that fetches current weather data from OpenWeather and displays it.

Features:
- Get weather for any location.
- Shows temperature, conditions, and a icon.
- Uses OpenWeather API

Set up
1. Clone the repo
2. Replace the API key on line 8 of Weather,py with your OpenWeather API
3. Install dependencies : requests, python-dotenv, and flask
4. Then run app.py and open in your browser
